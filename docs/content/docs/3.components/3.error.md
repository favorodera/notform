---
title: Error
description: Render the first validation error for a field without managing message state yourself.
---

`<Error>` displays the first active validation message for a field.

By default it renders a `<span>`. When the field has no active error, it renders nothing.

## Usage

```vue
<template>
  <Field
    v-slot="{ events, path }"
    path="email"
  >
    <input
      :id="path"
      v-model="form.values.email"
      v-bind="events"
      type="email"
    >

    <Error :path="path" />
  </Field>
</template>
```

## Props

| Prop | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | `Path<TSchema>` | Yes | — | Field path whose first current issue is shown |
| `form` | `UseFormReturn<TSchema>` | No | Injected form | Explicit instance that takes priority over the nearest `<Form>` |
| `as` | `Component \| string` | No | `'span'` | Element or component used for the message |

## Custom element

```vue
<template>
  <Error
    path="email"
    as="p"
    class="text-red-500"
  />
</template>
```

## Custom component

```vue
<template>
  <Error
    :as="ErrorMessage"
    path="email"
  />
</template>
```

When `as` is a component, the message is passed through its default slot.

If your component expects a `message` prop instead, use the `Error` default slot:

```vue
<template>
  <Error
    v-slot="{ message }"
    path="email"
  >
    <ErrorMessage
      v-if="message"
      :message="message"
    />
  </Error>
</template>
```

## Slot: `default`

| Prop | Type | Description |
| --- | --- | --- |
| `message` | `string \| undefined` | First active error message for the field |

Example:

```vue
<template>
  <Error
    v-slot="{ message }"
    path="email"
  >
    <MyErrorMessage
      v-if="message"
      :message="message"
    />
  </Error>
</template>
```

## Multiple errors

`Error` intentionally renders one message.

Use the `errors` slot prop from `<Field>` when you need every issue:

```vue
<template>
  <Field
    v-slot="{ errors, events, path }"
    path="password"
  >
    <input
      :id="path"
      v-model="form.values.password"
      v-bind="events"
    >

    <ul>
      <li
        v-for="error in errors"
        :key="error.message"
      >
        {{ error.message }}
      </li>
    </ul>
  </Field>
</template>
```

## Attributes

Attributes that are not props, such as `class`, `id`, and `data-*`, are forwarded to the rendered element.
