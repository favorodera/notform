---
title: NotForm
description: Wrap a native form, provide form context, and connect submit and reset events.
---

`<NotForm>` is the native-form bridge for NotForm.

It renders a real `<form>` element, provides the form instance to descendant field components, and prevents the browser's native reset action. Submit prevention belongs to `form.submit()`, so binding `@submit="form.submit"` lets the form instance prevent navigation and run validation.

It does not automatically call `form.submit()` or `form.reset()` for you.

## Usage

```vue
<template>
  <NotForm
    :form="form"
    @submit="form.submit"
    @reset="form.reset()"
  >
  <!-- fields -->
  </NotForm>
</template>
```

The component is optional. You can pass `form` directly to the field components instead.

## Native form behavior

Because `<NotForm>` renders a native `<form>`, normal attributes remain available:

```vue
<template>
  <NotForm
    :form="form"
    method="post"
    action="/account"
    novalidate
    @submit="form.submit()"
  >
    ...
  </NotForm>
</template>
```

Use `novalidate` when you want NotForm's validation UI to be the only validation UI shown.

## Context

Descendant `<NotField>`, `<NotArrayField>`, and `<NotMessage>` components can resolve the nearest form automatically.

An explicit `form` prop on a component takes priority over injected context.

## Props

| Prop | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `form` | `NotFormAPI<TSchema>` | Yes | — | Form instance returned by `useNotForm()` |

## Slots

| Slot | Props | Description |
| --- | --- | --- |
| `default` | — | Form content rendered inside the native `<form>` |

## Submit and reset

`<NotForm>` prevents the browser's native reset behavior. Submit prevention happens inside `form.submit()` when it receives the native event. Your event handlers decide what NotForm should do:

```vue
<template>
  <NotForm
    :form="form"
    @submit="form.submit"
    @reset="form.reset()"
  >
    ...
  </NotForm>
</template>
```

This separation keeps native browser behavior predictable and leaves programmatic control available too.
