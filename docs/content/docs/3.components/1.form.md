---
title: Form
description: Render a native form, provide form context, and connect submit and reset events.
---

`<Form>` renders a native `<form>` and provides its form instance to descendant components.

The component prevents the browser's native reset action. Bind `@submit="form.submit"` to prevent native submission and start validation.

`Form` does not call `form.submit()` automatically. It also does not reset form state unless you bind `@reset="form.reset()"`.

## Usage

```vue
<template>
  <Form
    :form="form"
    @submit="form.submit"
    @reset="form.reset()"
  >
  <!-- fields -->
  </Form>
</template>
```

The component is optional. You can pass `form` directly to the field components instead.

## Native form behavior

Because `<Form>` renders a native `<form>`, normal attributes remain available:

```vue
<template>
  <Form
    :form="form"
    method="post"
    action="/account"
    novalidate
    @submit="form.submit()"
  >
    ...
  </Form>
</template>
```

Use `novalidate` when NotForm should provide the only validation feedback.

## Context

Descendant `<Field>`, `<ArrayField>`, and `<Error>` components can resolve the nearest form automatically.

An explicit `form` prop on a component takes priority over injected context.

## Props

| Prop | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `form` | `UseFormReturn<TSchema>` | Yes | — | Instance returned by `useForm()` and provided to descendants |

## Slots

| Slot | Props | Description |
| --- | --- | --- |
| `default` | — | Form content rendered inside the native `<form>` |

## Submit and reset

`Form` prevents native reset behavior. `form.submit()` prevents the native submit event when it receives that event. Bind each action explicitly:

```vue
<template>
  <Form
    :form="form"
    @submit="form.submit"
    @reset="form.reset()"
  >
    ...
  </Form>
</template>
```

You can also call `form.submit()` or `form.reset()` directly from application code.
