title: useForm
description: Create a typed reactive form from a Standard Schema-compatible object schema. Full configuration and instance reference.
---

`useForm` creates the form instance that owns values, errors, field instances, and submit state. Call it in a Vue setup context (`<script setup>` or `setup()`), so its timers and watchers are cleaned up when the component unmounts.

```ts
import { useForm } from 'notform'
import { z } from 'zod'

const form = useForm({
  initialValues: { displayName: '', email: '' },
  onSubmit(data) {
    console.log(data)
  },
  schema: z.object({
    displayName: z.string().min(1),
    email: z.email(),
  }),
})
```

In Nuxt, `useForm` is auto-imported. See the [Nuxt module guide](/docs/getting-started/nuxt-module).

## Configuration

::field-group
  :::field{required name="schema" type="MaybeRefOrGetter<TSchema>"}
  A Standard Schema-compatible **object** schema. May be a value, a ref, or a getter. It is read each time validation runs.
  :::

  :::field{name="initialValues" type="DeepPartial<SchemaInput<TSchema>>"}
  Starting values and the baseline for `isDirty` and `reset()`. May be partial, but provide a value for every bound field.
  :::

  :::field{name="initialErrors" type="ValidationIssue[]"}
  Issues shown before the first validation. An issue without a `path` is form-level.
  :::

  :::field{name="onSubmit" type="(data: SchemaOutput<TSchema>) => void | Promise<void>"}
  Called after the whole form validates. The argument is the parsed schema **output**.
  :::
::

## Returned instance

The returned object is reactive. Read members directly, for example `form.isDirty`.

### State

| Member | Type | Description |
| --- | --- | --- |
| `values` | `SchemaInput<TSchema>` | Live input values. Editable directly, through `setValue`, or through field models. |
| `errors` | `ValidationIssue[]` | Current issues. Empty when nothing is wrong. |
| `isDirty` | `boolean` | Values differ from the baseline. |
| `isTouched` | `boolean` | A field blurred or a submit was attempted. |
| `isSubmitted` | `boolean` | At least one submit was attempted. |
| `isSubmitting` | `boolean` | Validation or `onSubmit` is running. |
| `isValidating` | `boolean` | A validation is running. |
| `isValid` | `boolean` | The error list is empty. Does not validate. |
| `submitCount` | `number` | Submit attempts since the last reset. |
| `resetCount` | `number` | Number of resets. |

### Fields

| Member | Description |
| --- | --- |
| `field(path, config?)` | Get or create the cached field for a typed input path. |
| `arrayField(path, config?)` | Get or create the cached array field for a typed array path. |

The first call for a path creates the field and reads `config`. Later calls return the same instance and ignore any config. See [Validation](/docs/guides/validation#configure-a-field).

### Actions

| Member | Description |
| --- | --- |
| `submit(event?)` | Validate the form and call `onSubmit` if it passes. Prevents the event's default action. Ignored while a submit is running. Rejects if `onSubmit` throws. |
| `validate()` | Validate the whole form without calling `onSubmit`. Replaces all errors. Resolves with `{ value }` or `{ issues }`. |
| `reset(values?, errors?)` | Restore the baseline, or replace it when arguments are given. Clears touched and submit state. |
| `setError(issue)` | With a `path`, replaces errors at that path. Without, appends a form-level error. |
| `setValue(path, value)` | Write a typed input value. Does not validate. |

## Typed paths and values

Paths use dot notation and are checked against the schema **input**. `form.field('address.city')` targets a nested value, and `form.arrayField('contacts')` targets an array. Values in `form.values` use the input type, and `onSubmit` receives the output type. See [Schema input and output](/docs/guides/schema-input-output) and [TypeScript](/docs/guides/typescript).

## Notes

- Call `useForm` once per form. Each call creates an independent form.
- Outside a Vue setup context, cleanup on unmount does not run.
- Changing a reactive `schema` discards in-flight validations but does not re-validate.
- The returned type is `UseFormInstance<TSchema>`, the public contract documented here.
