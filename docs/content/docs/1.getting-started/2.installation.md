---
title: Installation
description: Install NotForm in a Vue 3 or Nuxt application.
---

NotForm is split into a core package and an optional Nuxt integration. You also choose the validation library; NotForm does not bundle a validator.

## Vue 3

Install the core package:

::code-group
```bash [npm]
npm install notform
```
```bash [pnpm]
pnpm add notform
```
```bash [yarn]
yarn add notform
```
```bash [bun]
bun add notform
```
::

Then install a Standard Schema-compatible validator. For example, with Zod:

::code-group
```bash [npm]
npm install zod
```
```bash [pnpm]
pnpm add zod
```
```bash [yarn]
yarn add zod
```
```bash [bun]
bun add zod
```
::

Import the APIs you use from `notform`:

```ts
import { ArrayField, Error, Field, Form, useForm } from 'notform'
```

## Nuxt

Install the official Nuxt module and your validator:

::code-group
```bash [npm]
npm install @notform/nuxt zod
```
```bash [pnpm]
pnpm add @notform/nuxt zod
```
```bash [yarn]
yarn add @notform/nuxt zod
```
```bash [bun]
bun add @notform/nuxt zod
```
::

Register the module in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ['@notform/nuxt'],
})
```

The module auto-imports `useForm`, `Form`, `Field`, `ArrayField`, and `Error`. See [Nuxt](/docs/getting-started/nuxt) for alias configuration and integration details.

## Requirements

The core package targets Vue 3.5 or newer and declares Node.js 24 or newer in its package requirements. 

The Nuxt integration targets Nuxt 4.6 or newer and also requires Node.js 24 or newer.

NotForm works with any Standard Schema-compatible validator; the validator remains a separate dependency in your application.

## Verify the setup

The smallest useful check is a form instance with a schema:

```ts
import { useForm } from 'notform'
import { z } from 'zod'

const schema = z.object({
  email: z.email(),
})

const form = useForm({
  schema,
})
```

Continue with [Quickstart](/docs/getting-started/quickstart) to connect that form to a template.
