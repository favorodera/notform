NotForm is distributed as a single npm package, `notform`{lang="ts-type"}, and can be used directly in any Vue 3 application — no build plugin, compiler macro, or bundler configuration required.

::note
If you are using Nuxt, skip ahead to the [Nuxt](#nuxt) section below and use the official [Nuxt Module](/getting-started/nuxt-module) instead of the manual steps here. It handles imports and setup for you.
::

## Install the package

NotForm validates values using [Standard Schema](https://standardschema.dev) rather than a validation language of its own. This means NotForm doesn't ship a validator — you bring your own compatible library alongside it. Popular options include [Zod](https://zod.dev), [Valibot](https://valibot.dev), and [ArkType](https://arktype.io).

Pick one of these (this guide uses `zod`{lang="ts-type"} in its examples) and install it together with `notform`{lang="ts-type"} using your preferred package manager:

::code-group
```bash [pnpm]
pnpm add notform zod
```

```bash [yarn]
yarn add notform zod
```

```bash [npm]
npm install notform zod
```

```bash [bun]
bun add notform zod
```
::

::note
You can replace `zod`{lang="ts-type"} with another Standard Schema-compatible validation library if you prefer. Every code example in these docs uses `zod`{lang="ts-type"}, but nothing about NotForm's API changes based on which validator you choose.
::

## Vue and Vite

NotForm is designed for Vue 3 and works with standard Vue applications out of the box — there is no application-level setup step, plugin installation, or provider component to configure before you can use it.

Once installed, import the components and composables you need directly from `notform`{lang="ts-type"}:

```vue [App.vue]
<script setup lang="ts">
import { NotField, NotForm, NotMessage, useNotForm } from 'notform'
import { z } from 'zod'

const schema = z.object({
  email: z.email('Invalid email'),
})

const form = useNotForm({
  onSubmit(values) {
    console.log('Form submitted:', values)
  },
  schema,
})
</script>

<template>
  <NotForm
    :form="form"
    @submit="form.submit"
  >
    <!-- form fields go here -->
  </NotForm>
</template>
```

NotForm follows the normal Vue component model: there is no global registration step, and nothing is installed as a Vue plugin. Import only the pieces you actually use — `useNotForm`{lang="ts-type"} to create the form instance, `<NotForm>`{lang="vue"} to provide it to your fields, and `<NotField>`{lang="vue"} / `<NotArrayField>`{lang="vue"} / `<NotMessage>`{lang="vue"} for the fields themselves.

The full breakdown of this example — defining a schema, wiring up individual fields, and displaying validation messages — is covered step by step in [Quickstart](/getting-started/quickstart).

## Nuxt

For Nuxt applications, use the [Nuxt Module](/getting-started/nuxt-module) rather than manually installing and importing `notform`{lang="ts-type"} as shown above.

The module installs the package for you, registers every component and composable as a Nuxt auto-import, and wires up type support — so you can start writing `<NotForm>`{lang="vue"} and `useNotForm`{lang="ts-type"} directly in your `.vue`{lang="text"} files without an `import`{lang="ts-type"} statement.
