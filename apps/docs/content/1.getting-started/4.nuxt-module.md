The official `notform-nuxt`{lang="ts-type"} module provides a first-class developer experience for using NotForm in Nuxt applications. It handles component and composable registration automatically.

## Installation

The module is registered in the official Nuxt Modules Registry, meaning you can easily install it using the Nuxt CLI.

::code-group
```bash [npx]
npx nuxi module add notform
```
```bash [pnpm]
pnpm dlx nuxi module add notform
```
```bash [bun]
bunx nuxi module add notform
```
```bash [yarn]
yarn dlx nuxi module add notform
```
::

::note
This command will automatically install `notform-nuxt`{lang="ts-type"} and add it to the `modules`{lang="ts-type"} array in your `nuxt.config.ts`{lang="ts-type"}. You still need to install your preferred validation library (e.g., `zod`{lang="ts-type"}).
::

```bash
pnpm add zod
```

## Manual Setup

If you prefer to install manually, add the dependency:

```bash
pnpm add notform-nuxt
```

Then, add it to your `nuxt.config.ts`{lang="ts-type"}:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['notform-nuxt'],
})
```

## Features

### Auto-imports

All core components and composables are available globally in your Vue files without any manual imports.

::field-group
  :::field{name="useNotForm" type="Composable"}
  The core form management composable.
  :::

  :::field{name="<NotForm>" type="Component"}
  Context provider and `<form>`{lang="vue"} wrapper.
  :::

  :::field{name="<NotField>" type="Component"}
  Renderless wrapper for single fields.
  :::

  :::field{name="<NotMessage>" type="Component"}
  Error message renderer.
  :::

  :::field{name="<NotArrayField>" type="Component"}
  Renderless wrapper for dynamic array fields.
  :::
::

### Type Safety

Needed types from the core `notform`{lang="ts-type"} package are automatically injected into your project's global types for perfect IntelliSense.

### Server-side Rendering (SSR)

NotForm is fully compatible with Nuxt's SSR engine. Form state and validation rules are safely executed on the server during the initial render without hydration mismatches.
