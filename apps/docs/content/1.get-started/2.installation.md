Get up and running with NotForm in just a few steps. Learn how to install the core package and plug in your favorite validation library.

## Install notform

::code-group
```bash [pnpm]
pnpm add notform
```
```bash [yarn]
yarn add notform
```
```bash [npm]
npm install notform
```
```bash [bun]
bun add notform
```
::

## Install a validation library

NotForm accepts any [Standard Schema](https://standardschema.dev){target="_blank" rel="noopener noreferrer"} compliant validator. Pick one.

::code-group
```bash [Zod]
pnpm add zod
```
```bash [Valibot]
pnpm add valibot
```
```bash [ArkType]
pnpm add arktype
```
```bash [Yup]
pnpm add yup
```
::

::note
You only need **one** library. Though NotForm works with any [Standard Schema](https://standardschema.dev){target="_blank" rel="noopener noreferrer"} compliant validator, NotForm's API does not change between validators.
::
