NotForm includes Agent Skills for AI coding assistants. Skills help an agent choose the right NotForm workflow, then point it to the published documentation for complete API details.

Skills are routing and procedure guidance. They do not replace the NotForm documentation, and they do not replace your project's tests, typechecking, or code review.

NotForm provides four focused skills:

| Skill | Use it when |
| --- | --- |
| `composables`{lang="ts-type"} | You use `useNotForm`{lang="ts-type"}, schemas, values, validation, errors, submit, or reset. |
| `components`{lang="ts-type"} | You use `<NotForm>`{lang="vue"}, `<NotField>`{lang="vue"}, `<NotArrayField>`{lang="vue"}, `<NotMessage>`{lang="vue"}, slots, custom inputs, or dynamic arrays. |
| `nuxt`{lang="ts-type"} | You configure `notform-nuxt`{lang="ts-type"}, auto-imports, SSR, or Nuxt documentation. |
| `debugging`{lang="ts-type"} | You troubleshoot validation, state, messages, submission, arrays, or integration. |

## Usage

Each skill starts with a task map and links to the matching raw documentation. The intended flow is:

1. Load the relevant skill from the project.
2. Fetch [`llms.txt`{lang="ts-type"}](https://notformdocs.vercel.app/llms.txt) or [`llms-full.txt`{lang="ts-type"}](https://notformdocs.vercel.app/llms-full.txt) depending on the areas the task touches.
3. Fetch the focused raw page, such as [`<NotField>`{lang="vue"}](https://notformdocs.vercel.app/raw/docs/components/not-field.md) or [`useNotForm`{lang="ts-type"}](https://notformdocs.vercel.app/raw/docs/composables/use-not-form.md).
4. Implement against the documented API, then validate in the user's application.

::tip
Read [llms.txt](/docs/working-with-ai/llms.txt) for the full context-loading strategy.
::

### Install the skills

The [`skills`{lang="ts-type"}](https://skills.sh) CLI is the easiest way to install the NotForm skills set. It supports 35+ agents including Cursor, Claude Code, Codex, Windsurf, Cline, and more.

::code-group

```bash [npm]
npx skills add favorodera/notform
```

```bash [pnpm]
pnpm dlx skills add favorodera/notform
```

```bash [yarn]
yarn dlx skills add favorodera/notform
```

```bash [bun]
bunx skills add favorodera/notform
```
::

You can target specific agents with the `--agent` flag:

::code-group

```bash [npm]
npx skills add favorodera/notform --agent cursor
npx skills add favorodera/notform --agent claude-code
```

```bash [pnpm]
pnpm dlx skills add favorodera/notform --agent cursor
pnpm dlx skills add favorodera/notform --agent claude-code
```

```bash [yarn]
yarn dlx skills add favorodera/notform --agent cursor
yarn dlx skills add favorodera/notform --agent claude-code
```

```bash [bun]
bunx skills add favorodera/notform --agent cursor
bunx skills add favorodera/notform --agent claude-code
```
::

Or install globally so the skill is available across all your projects:

::code-group

```bash [npm]
npx skills add favorodera/notform --global
```

```bash [pnpm]
pnpm dlx skills add favorodera/notform --global
```

```bash [yarn]
yarn dlx skills add favorodera/notform --global
```

```bash [bun]
bunx skills add favorodera/notform --global
```
::
