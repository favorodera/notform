The NotForm Agent Skill helps AI coding assistants work with NotForm in Vue and Nuxt applications. It guides agents through setup, forms, components, validation, debugging, and integration, then points to focused references and published documentation for API details.

The skill provides workflow guidance. It complements the NotForm documentation and your project's tests, typechecking, and code review.

## Usage

The skill starts with a task map and links to the matching raw documentation. The intended flow is:

1. Load the relevant reference based on the task.
2. Fetch [`llms.txt`{lang="ts-type"}](/llms.txt){external} or [`llms-full.txt`{lang="ts-type"}](/llms-full.txt){external} depending on the areas the task touches.
3. Fetch the focused raw page, such as [`<NotField>`{lang="vue"}](/raw/docs/components/not-field.md){external} or [`useNotForm`{lang="ts-type"}](/raw/docs/composables/use-not-form.md){external}.
4. Implement against the documented API, then validate in the user's application.

::tip
Read [working-with-ai/llms-txt](/docs/working-with-ai/llms-txt) for the full context-loading strategy.
::

### Install the skill

Use the [`skills`{lang="ts-type"}](https://skills.sh){external target="_blank"} CLI to install NotForm's Agent Skill. It supports more than 35 agents, including Cursor, Claude Code, Codex, Windsurf, and Cline.

Run one of these commands in your project:

::code-group

```bash [npm]
npx skills add favorodera/notform
```

```bash [pnpm]
pnpm dlx skills add favorodera/notform
```

```bash [yarn]
yarn dlx skills add favorodera/notform
```

```bash [bun]
bunx skills add favorodera/notform
```
::
