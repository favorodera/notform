NotForm publishes machine-readable documentation so coding assistants can load the right context without parsing the entire site.

## `/llms.txt`

[`/llms.txt`](/llms.txt){external} is the compact documentation index.

Use it first when an assistant needs to understand NotForm and choose the most relevant page.

## `/llms-full.txt`

[`/llms-full.txt`](/llms-full.txt){external} contains the full documentation bundle.

Use it when a task crosses several areas, such as installation, field components, validation, arrays, and Nuxt.

## Raw Markdown pages

Each documentation page is also available as Markdown below `/raw`.

```text
/raw/docs/getting-started/quickstart.md
/raw/docs/concepts/validation.md
/raw/docs/components/not-field.md
/raw/docs/composables/use-not-form.md
```

Raw pages are useful when an assistant needs exact API tables or examples without the site's rendered presentation.

## Recommended context flow

For a focused task:

```text
llms.txt
  → choose the page
  → read the raw page
  → implement against the documented API
  → typecheck and test
```

For a broad task:

```text
llms-full.txt
  → identify the relevant sections
  → read focused raw pages
  → implement
  → verify in the application
```

## Why this exists

NotForm's API is strongly typed, but small differences in validation scope, field triggers, and array behavior can be easy to get wrong from memory.

The machine-readable documentation gives AI assistants a stable source of truth for those details.
