NotForm ships an Agent Skill for coding assistants working on Vue 3 and Nuxt applications.

The skill is a routing and context layer. It helps an agent identify the relevant NotForm APIs before changing application code, then points it back to tests and documentation for verification.

## Install

Use the [`skills`](https://www.skills.sh/){external target="_blank"} CLI:

::code-group

```bash [npm]
npx skills add favorodera/notform
```

```bash [pnpm]
pnpm dlx skills add favorodera/notform
```

```bash [yarn]
yarn dlx skills add favorodera/notform
```

```bash [bun]
bunx skills add favorodera/notform
```
::

## What the skill covers

| Task | Read |
| --- | --- |
| Create a form, validate, submit, reset, handle errors | [`useNotForm`](/docs/composables/use-not-form) |
| Connect inputs and control validation timing | [`NotField`](/docs/components/not-field) |
| Render native form context | [`NotForm`](/docs/components/not-form) |
| Render validation messages | [`NotMessage`](/docs/components/not-message) |
| Build repeatable and nested fields | [`NotArrayField`](/docs/components/not-array-field) |
| Understand validation lifecycle | [`Validation`](/docs/concepts/validation) |
| Configure Nuxt | [`Nuxt`](/docs/getting-started/nuxt) |

## Recommended workflow

1. Identify which part of the form is changing.
2. Read the matching documentation page.
3. Use [`llms.txt`](/llms.txt){external} or [`llms-full.txt`](/llms-full.txt){external} when the task spans multiple areas.
4. Implement against the documented API.
5. Run typechecking and tests.
6. Verify the behavior in the target application.

::note
The Agent Skill does not replace the documentation or the project's test suite. It exists to help assistants reach the correct information faster.
::
