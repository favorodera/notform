NotForm has an official Nuxt module named `notform-nuxt`.

The module adds the core NotForm composable and components to Nuxt's auto-import system. It does not change the form API and it does not install a validator for you.

## Install

The recommended installation is:

::code-group
```bash [npm]
npx nuxi module add notform
```
```bash [pnpm]
pnpm dlx nuxi module add notform
```

```bash [yarn]
tarn dlx nuxi module add notform
```

```bash [bun]
bunx nuxi module add notform
```
::

Then install a Standard Schema-compatible validator, for example:

::code-group
```bash [npm]
npm install zod
```
```bash [pnpm]
pnpm add zod
```

```bash [yarn]
yarn add zod
```

```bash [bun]
bun add zod
```
::

## Manual setup

When installing the package directly:

::code-group
```bash [npm]
npm install notform-nuxt
```
```bash [pnpm]
pnpm add notform-nuxt
```

```bash [yarn]
yarn add notform-nuxt
```

```bash [bun]
bun add notform-nuxt
```
::

Register the module in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: [
    'notform-nuxt',
  ],
})
```

## Auto-imports

The module makes these APIs available without imports in Nuxt components:

| API | Kind | Purpose |
| --- | --- | --- |
| `useNotForm` | composable | Create the form instance |
| `NotForm` | component | Render the native form and provide context |
| `NotField` | component | Connect an individual field |
| `NotArrayField` | component | Manage repeatable fields |
| `NotMessage` | component | Render a field's first error message |

Your validator is still a normal application dependency:

```vue
<script setup lang="ts">
import { z } from 'zod'

const schema = z.object({
  email: z.email(),
})

const form = useNotForm({
  schema,
})
</script>
```

The Nuxt module only wires imports and components into the Nuxt application. Form state still belongs to the component instance created by `useNotForm`.

Create form instances in normal Vue setup code. Do not keep one form instance in module scope and reuse it across requests.

## What the module does not do

The module does not:

- choose a validation library
- add styling
- replace the NotForm API
- submit forms automatically
- persist form state between requests

It is an integration layer, not a second form library.
