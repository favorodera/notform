---
title: Installation
description: Install NotForm in a Vue 3 or Nuxt application.
---

NotForm is split into a small core package and an optional Nuxt integration.

You also choose the validation library. NotForm does not bundle a validator.

## Vue 3

Install the core package:

::code-group
```bash [npm]
npm install notform
```
```bash [pnpm]
pnpm add notform
```

```bash [yarn]
yarn add notform
```

```bash [bun]
bun add notform
```
::

Then install a Standard Schema-compatible validator. For example, with Zod:

::code-group
```bash [npm]
npm install zod
```
```bash [pnpm]
pnpm add zod
```

```bash [yarn]
yarn add zod
```

```bash [bun]
bun add zod
```
::

Import the APIs you use from `notform`:

```ts
import { NotField, NotForm, NotMessage, useNotForm } from 'notform'
```

## Nuxt

The recommended setup is the Nuxt module:

::code-group
```bash [npm]
npx nuxi module add notform
```
```bash [pnpm]
pnpm dlx nuxi module add notform
```

```bash [yarn]
tarn dlx nuxi module add notform
```

```bash [bun]
bunx nuxi module add notform
```
::

This adds the official `notform-nuxt` module and configures it for your Nuxt app.

Then Install your validator separately:

::code-group
```bash [npm]
npm install zod
```
```bash [pnpm]
pnpm add zod
```

```bash [yarn]
yarn add zod
```

```bash [bun]
bun add zod
```
::

The module provides auto-imports for `useNotForm`, `NotForm`, `NotField`, `NotArrayField`, and `NotMessage`.

See [Nuxt](/docs/getting-started/nuxt) for manual setup and integration details.

## Requirements

The core package targets Vue 3. The current repository and package tooling require Node.js 24 or newer for development and builds.

NotForm works with any Standard Schema-compatible validator; the validator remains a separate dependency in your application.

## Verify the setup

The smallest useful check is a form instance with a schema:

```ts
import { useNotForm } from 'notform'
import { z } from 'zod'

const schema = z.object({
  email: z.email(),
})

const form = useNotForm({
  schema,
})
```

Continue with [Quickstart](/docs/getting-started/quickstart) to connect that form to a template.
