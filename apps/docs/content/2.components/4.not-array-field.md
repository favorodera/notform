`<NotArrayField>`{lang="vue"}  is a renderless component for working with array fields in a form.

It provides the current array items, stable keys and field paths for rendering nested fields, validation state, and methods for adding, removing, updating, inserting, swapping, and moving items.

## API

### Props


::field-group
  :::field{name="path" type="Paths<TSchema>" required}
  Dot path of the array field. It identifies the array field managed by `<NotArrayField>`{lang="vue"}

  ```vue
  <template>
    <NotArrayField path="todos">
      ...
    </NotArrayField>
  </template>
  ```

  For nested arrays use dot notation:

  ```vue
  <template>
    <NotArrayField path="user.todos">
      ...
    </NotArrayField>
  </template>
  ```

  The same path is exposed through the default slot and can be used for labels, IDs, messages, and other field-specific elements.
  :::

  :::field{name="form" type="NotFormAPI<TSchema>"}
  Form instance. Overrides `<NotArrayField>`{lang="vue"} inject.

  <br><br>

  By default, `<NotArrayField>`{lang="vue"} uses the form instance provided by a surrounding `<NotForm>`{lang="vue"}.

  <br><br>

  You can explicitly provide a form instance when needed:

  ```vue
  <template>
    <NotArrayField
      :form="form"
      path="todos"
    >
      ...
    </NotArrayField>
  </template>
  ```

  An explicit `form`{lang="ts-type"} takes priority over the form provided by a `<NotForm>`{lang="vue"} ancestor.

  <br><br>

  This is also required when using `<NotArrayField>`{lang="vue"} as a standalone component outside of a `<NotForm>`{lang="vue"}.
  :::

  :::field{name="itemSchema" type="TItemSchema"}
  The schema for an array item.

  <br><br>

  It is used for type inference only so that array mutation methods such as `append`{lang="ts-type"}, `prepend`{lang="ts-type"}, `insert`{lang="ts-type"}, and `update`{lang="ts-type"} receive the correct types.

  ```vue
  <script setup lang="ts">
  import { z } from 'zod'
  
  const itemSchema = z.object({
    done: z.boolean(),
    title: z.string(),
  })
  </script>
  
  <template>
    <NotArrayField
      v-slot="{ append }"
      path="todos"
      :item-schema="itemSchema"
    >
      <button
        type="button"
        @click="append({ title: '', done: false })"
      >
        Add Todo
      </button>
    </NotArrayField>
  </template>
  ```
  :::
::

### Slots

#### `default`{lang="ts-type"}
The default slot receives the full array state and all available array operations.

```vue
<template>
  <NotArrayField
    v-slot="slotProps"
    path="todos"
  >
    ...
  </NotArrayField>
</template>
```

::field-group
  :::field{name="path" type="string"}
  Dot path of this array field.

  <br><br>

  Useful for labels, inputs, IDs, messages, and other field-specific elements.

  ```vue
  <template>
    <NotArrayField
      v-slot="{ path }"
      path="todos"
    >
      <NotMessage :path="path" />
    </NotArrayField>
  </template>
  ```
  :::

  :::field{name="errors" type="Array<Issue>"}
  Validation issues for this array field path.

  <br><br>

  It contains all validation issues reported for the array field during the most recent validation run.

  ```vue
  <template>
    <NotArrayField
      v-slot="{ errors }"
      path="todos"
    >
      <input v-model="form.values.todos">
  
      <ul v-if="errors.length > 0">
        <li
          v-for="error in errors"
          :key="error.message"
        >
          {{ error.message }}
        </li>
      </ul>
    </NotArrayField>
  </template>
  ```
  :::

  :::field{name="isValid" type="boolean"}
  Whether the array field and all item fields has no issues.

  <br><br>

  It is `true`{lang="ts-type"} if the array field and its items has no issues and `false`{lang="ts-type"} otherwise.

  ```vue
  <template>
    <NotArrayField
      v-slot="{ isValid }"
      path="todos"
    >
      <span v-if="isValid">Valid</span>
    </NotArrayField>
  </template>
  ```
  :::

  :::field{name="isTouched" type="boolean"}
  Whether the user has interacted with any item field.

  <br><br>

  This can be useful for displaying validation feedback only after the user has interacted with the field:

  ```vue
  <template>
    <NotArrayField
      v-slot="{ isTouched, isValid }"
      path="tags"
    >
      <p v-if="isTouched && !isValid">
        Please enter a valid tags.
      </p>
    </NotArrayField>
  </template>
  ```
  :::

  :::field{name="isDirty" type="boolean"}
  Whether the value of any item field differs from the baseline.

  ```vue
  <template>
    <NotArrayField
      v-slot="{ isDirty }"
      path="todos"
    >
      <span v-if="isDirty">Unsaved changes</span>
    </NotArrayField>
  </template>
  ```
  :::

  :::field{name="isValidating" type="boolean"}
  Whether any item field is currently validating.

  ```vue
  <template>
    <NotArrayField
      v-slot="{ isValidating }"
      path="skills"
    >
      <span v-if="isValidating">
        Personalizing your feed...
      </span>
    </NotArrayField>
  </template>
  ```
  :::

  :::field{name="items" type="Array<NotArrayFieldItem<TSchema>>"}
  Contains metadata for every item in the array.

  <br><br>

  Each item has:

    ::field-group
      ::field{name="key" type="string"}
      A stable identity for `v-for`{lang="ts-type"} `:key`{lang="ts-type"} that remains the same even if the item's position changes
      ::

      ::field{name="path" type="string"}
      The dot path of this item at its **current** index
      ::

      ::field{name="index" type="number"}
      The item's current position in the array
      ::
    ::

    ::note
    The `key`{lang="ts-type"} remains stable when items are reordered, while `index`{lang="ts-type"} and `path`{lang="ts-type"} change with the item's current position.
    ::
  :::

  :::field{name="append" type="(value: InferInput<TItemSchema>) => void"}
  Appends a value to the end of the array.

  ```vue
  <template>
    <NotArrayField
      v-slot="{ append }"
      path="items"
    >
      <button
        type="button"
        @click="append({ name: 'New Item' })"
      >
        Add Item
      </button>
    </NotArrayField>
  </template>
  ```
  :::
::
