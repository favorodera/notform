`<NotArrayField>`{lang="vue"}  is a renderless component for working with array fields in a form.

It provides the current array items, stable keys and field paths for rendering nested fields, validation state, and methods for adding, removing, updating, inserting, swapping, and moving items.

## API

### Props


::field-group
  :::field{name="path" type="Paths<TSchema>" required}
  Dot path of the array field. It identifies the array field managed by `<NotArrayField>`{lang="vue"}

  ```vue
  <template>
    <NotArrayField path="todos">
      ...
    </NotArrayField>
  </template>
  ```

  For nested arrays use dot notation:

  ```vue
  <template>
    <NotArrayField path="user.todos">
      ...
    </NotArrayField>
  </template>
  ```

  The same path is exposed through the default slot and can be used for labels, IDs, messages, and other field-specific elements.
  :::

  :::field{name="form" type="NotFormAPI<TSchema>"}
  Form instance. Overrides `<NotArrayField>`{lang="vue"} inject.

  <br><br>

  By default, `<NotArrayField>`{lang="vue"} uses the form instance provided by a surrounding `<NotForm>`{lang="vue"}.

  <br><br>

  You can explicitly provide a form instance when needed:

  ```vue
  <template>
    <NotArrayField
      :form="form"
      path="todos"
    >
      ...
    </NotArrayField>
  </template>
  ```

  An explicit `form`{lang="ts-type"} takes priority over the form provided by a `<NotForm>`{lang="vue"} ancestor.

  <br><br>

  This is also required when using `<NotArrayField>`{lang="vue"} as a standalone component outside of a `<NotForm>`{lang="vue"}.
  :::

  :::field{name="itemSchema" type="TItemSchema"}
  The schema for an array item.

  <br><br>

  It is used for type inference only so that array mutation methods such as `append`{lang="ts-type"}, `prepend`{lang="ts-type"}, `insert`{lang="ts-type"}, and `update`{lang="ts-type"} receive the correct types.

  ```vue
  <script setup lang="ts">
  import { z } from 'zod'

  const itemSchema = z.object({
    done: z.boolean(),
    title: z.string(),
  })
  </script>

  <template>
    <NotArrayField
      v-slot="{ append }"
      path="todos"
      :item-schema="itemSchema"
    >
    <!-- Append arguments are now typed as { done: boolean; title: string } -->
     <button
       type="button"
       @click="append({ title: '', done: false })"
     >
       Add Todo
     </button>
    </NotArrayField>
  </template>
  ```
