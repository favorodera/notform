`<NotForm>`{lang="vue"} is the root component that wraps your form. It provides the form context to all child components and handles the native `submit`{lang="ts-type"} and `reset`{lang="ts-type"} events.

It automatically:

- Prevents the default browser form submission and reset behavior
- Provides the form context to all child `<NotField>`{lang="vue"} and `<NotArrayField>`{lang="vue"} components
- Handles form reset to clear validation errors and restore initial values

Under the hood, `<NotForm>`{lang="vue"} renders a native `<form>`{lang="vue"} element, which means:

- You can use native form attributes like `action`{lang="ts-type"}, `method`{lang="ts-type"}, `enctype`{lang="ts-type"}
- Form submission works with keyboard (Enter key) and accessibility tools
- The form integrates naturally with browser validation if needed

## Basic Usage

```vue
<script setup lang="ts">
import { NotForm, useNotForm } from 'notform'
import { z } from 'zod'

const schema = z.object({
  email: z.email('Invalid email'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
})

const form = useNotForm({
  onSubmit(values) {
    console.log('Form submitted:', values)
  },
  schema,
})
</script>

<template>
  <NotForm
    :form="form"
    @submit="form.submit"
    @reset="form.reset()"
  >
    <!-- Form fields go here -->
    <button type="submit">
      Submit
    </button>

    <button type="reset">
      Reset
    </button>
  </NotForm>
</template>
```

### Slots

#### `default`{lang="ts-type"}
The default slot for housing and providing the form instance to all form fields
