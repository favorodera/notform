# NotForm Agent Skill

Portable Agent Skill for using NotForm in Vue 3 and Nuxt applications.

## Layout

```text
notform/
  SKILL.md
  references/
    concepts.md
    components.md

```

## Reference map

| Reference | Use it for |
| --- | --- |
| `concepts.md` | Form state, validation, submission, arrays, server errors |
| `composables.md` | `useNotForm`, values, errors, validation, submit, reset |
| `components.md` | `NotForm`, `NotField`, `NotArrayField`, `NotMessage`, props, slots, events |
| `nuxt.md` | `notform-nuxt`, auto-imports, SSR-safe form-instance usage |
| `debugging.md` | Symptom routing and common integration mistakes |

The skill is a routing layer, not a second copy of the full product documentation. Use the linked raw pages for exact API details.
